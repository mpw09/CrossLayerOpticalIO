# Contributing

This repository is a controlled research-engineering project.

Contributions should preserve scientific correctness, explicit assumptions, provenance, reproducibility and the distinction between measured, simulated, modelled, calculated and sourced quantities.

Do not commit proprietary employer material, licensed standards/manuals without redistribution permission, secrets, or third-party datasets whose licence does not permit redistribution.

Before presenting a result as verified or validated, link it to the exact configuration, source identities, code revision, execution record and applicable acceptance criterion.
